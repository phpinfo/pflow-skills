# Russian docs

Adds to `SKILL.md` what is specific to Russian.

- Write in Russian, not a calque of English; if a sentence sounds translated, rewrite it. Simple links: «есть», «нужен», «ходит», «отдаёт».
- English only for names from code or protocols, in backticks (`GetPayment`). Replace English jargon in a Russian sentence («conditional update», «победитель») with what happens: «обновить с проверкой текущего статуса».
- Exception: established terms from the project glossary («поллинг»), written as there. The glossary may be missing or named differently; without one, prefer the Russian description.
- Quotes are «ёлочки».
- A dash between subject and predicate is grammar («Моби — наша ПС»), not a tell; one sentence still must not rest on several dashes.

## Phrases to avoid

| Avoid | Write | Why |
| --- | --- | --- |
| «Важно понимать, что…», «Стоит отметить…», «Давайте разберём…», «В этом разделе мы рассмотрим…» | the fact itself | run-up |
| «Таким образом, …», «Итак, …», «В итоге, …» closing a paragraph | cut | restating |
| «не X, а Y» when nobody claimed X; «не просто X, а Y» | «Y» | false contrast |
| «Это не значит, что…», «Можно было бы…, но…» | cut | arguing with no one |
| «ключевой», «критически важный», «играет важную роль», «мощный», «гибкий», «бесшовный» | what breaks without it, or a concrete property | inflation |
| «комплексный подход», «обеспечивает надёжность», «является неотъемлемой частью», «открывает новые возможности» | what exactly is done and what it gives | inflation |
| «является», «представляет собой» | «—», «это» or a verb | bureaucratese |
| «данный», «соответствующий», «определённый» | «этот», or name which one | bureaucratese |
| «в рамках», «в связи с этим», «с целью», «в случае если» | «в», «поэтому», «чтобы», «если» | bureaucratese |
| «на данный момент», «имеет место», «посредством» | «сейчас», «есть», «через» | bureaucratese |
| «осуществить сохранение», «производит проверку», «выполняет опрос» | «сохранить», «проверяет», «опрашивает» | verbal noun |
| «осуществляется», «производится» with no actor | active verb with a subject | hidden actor |
| «флаг позволяет отключить…» | «флаг отключает…» | calque of "allows" |
| «кроме того», «также», «помимо этого», «не менее важно» as openers | nothing | calque transition |
| «работает против тестового контура» | «работает на тестовом контуре» | calque of "against" |
| «зовёт» about code | «вызывает» | slang |
| «Надеюсь, это поможет», «Если нужно, могу…» | cut | chat residue |
